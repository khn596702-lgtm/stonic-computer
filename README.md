# STONIC Computer — Starter v0.1

## Included
- Mobile-friendly dashboard
- Server status endpoint
- Task manager saved in `stonic-data/tasks.json`
- Basic workspace file listing

## Run in GitHub Codespaces
1. Upload/extract these files into the root of your `stonic-computer` repository.
2. Open the terminal and run: `python3 server.py`
3. Open the **Ports** tab, make port `8000` visible, then open its forwarded URL.

## Limitations
This is a starter foundation, not a finished autonomous computer. Browser automation, AI, voice control, Android APK, authentication and 24/7 hosting are not included yet. Codespaces can stop when idle and has usage limits. Do not store secrets in this project.
